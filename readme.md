# 🤖 BRAM IS HERE — WhatsApp Bot

Bot WhatsApp Multi-Device dengan fitur lengkap: bug WhatsApp, download YouTube, dan banyak lagi.

## 🔥 Fitur

| Fitur | Perintah |
|-------|----------|
| Menu Utama | `!menu` |
| Cek Status | `!ping` |
| Info Bot | `!info` |
| Bug WhatsApp | `!brambug` / `!bbug` |
| Relay Spam | `!relay <nomor>` |
| Delay Payment | `!delay <nomor>` |
| Full Attack | `!fullbug <nomor>` |
| Download YouTube | `!yt <url>` |
| Bot Ngomong | `!say <teks>` |
| Hidetag | `!tag <teks>` |
| Sticker | `!sticker` |
